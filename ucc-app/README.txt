CIMPlicity AI - Release Notes

Version 1.0.4
- CIM data model fields (including calculated fields) are now loaded dynamically from the bundled model definitions instead of hardcoded lists.
- AI-assisted CIM mapping suggestions with configurable AI provider settings.
- PII detection during onboarding via bundled scrubadub, with Linux os-dependent numpy and regex libraries.
- Packaging and AppInspect compliance fixes.
